# ScreenOhRecord 1.2.3

- Floating controls appear automatically when you open or return to the main screen, once Display over other apps permission is enabled.
- Hide remains available and lasts until you return to the app.
- The main screen explains how to enable the permission. Missing or revoked permission does not automatically open Android settings.
- Showing controls never starts recording; Android capture consent is still required.
- Preserves settings, recordings, signing identity and updater. No new permissions or dependencies.

Install over the previous version without uninstalling. Android 16 emulator test results and limitations are recorded in TESTING.md. This update does not provide Google Play Protect clearance for the previously reported warning.
